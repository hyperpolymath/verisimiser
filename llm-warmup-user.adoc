= LLM Warmup — verisimiser (User)

== What is verisimiser?

A CLI that adds provenance, lineage, temporal versioning, access control, and
constraint/drift reporting to an existing PostgreSQL, SQLite, or MongoDB
database using sidecar storage. See link:README.adoc[README.adoc].

== Key Commands

[source,bash]
----
cargo install --path .            # install (needs Rust 1.85+ and a C compiler)
verisimiser init --database sqlite --name my-db
verisimiser validate
verisimiser status
verisimiser octad
verisimiser --help
----

With `just`: `just build`, `just install`, `just doctor`, `just help-me`.
There is no `just setup` or `just uninstall` recipe; uninstall with
`cargo uninstall verisimiser`.
