= LLM Warmup — verisimiser (Developer)

== What is verisimiser?

Augments an existing database with VeriSimiser's eight-concern Octad
(ADR-0004): data, metadata, provenance, lineage, constraints, access control,
temporal, simulation. VeriSimDB's upstream Octad is a different,
eight-modality model (ADR-0014). See link:README.adoc[README.adoc].

== Key Commands

* `just build` — `cargo build --release`
* `just test` — `cargo test` (CI also runs `--all-targets --no-fail-fast`)
* `just quality` — fmt-check + clippy + test
* `just deps` — Zig toolchain (fail-soft) + `cargo fetch`
* `just doctor` — toolchain/path diagnostics
* `just heal` — best-effort repair of permissions and caches
* `just doc-recipes` — verify docs reference only real recipes

There is no `just setup` or `just setup-dev`; use `cargo fetch` (or
`./setup.sh`, which falls back to `just doctor`).
