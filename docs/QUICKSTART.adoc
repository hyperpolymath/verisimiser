== Prerequisites

* **Rust 1.85+** (`rust-version` in `Cargo.toml`, edition 2024)
* **A C compiler** — `rusqlite` builds bundled SQLite from source
* **git** — `build.rs` stamps the binary with the current commit
* **Optional:** `just` for the task recipes (`cargo install just --locked`)

No additional system libraries are required beyond libc: SQLite is compiled
in, and nothing links OpenSSL.

== Sixty seconds

[source,bash]
----
git clone https://github.com/hyperpolymath/verisimiser.git
cd verisimiser
cargo install --path .          # -> $HOME/.cargo/bin/verisimiser
mkdir -p ~/projects/my-app
cd ~/projects/my-app
verisimiser init --database sqlite --name my-augmented-db
verisimiser validate
verisimiser status
----

`init` writes `verisimiser.toml` in the current directory; `validate` exits
non-zero if any manifest check fails.

== Running the test suite

[source,bash]
----
cd verisimiser
cargo test --all-targets --no-fail-fast     # what CI runs
just quality                                # fmt-check + lint + test
----

== What this repository does *not* give you yet

* **No published release.** The `v*`-tagged release workflow exists, but no
  tag or release has been created, so build from source.
* **No usable container.** `Containerfile` and `.devcontainer/` are RSR
  template stubs with `TODO` build steps and unfilled template metadata.
* **No `flake.nix`.** `guix.scm` is an experimental dev shell only.
* **No `just setup` / `just check-error-codes` / `just e2e` recipes.** Run
  `just --list` for the authoritative set; `just doc-recipes` checks that
  documentation does not reference recipes which do not exist.
